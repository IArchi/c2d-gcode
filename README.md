# Carbide Create to G-Code converter

`c2d-to-gcode` is a small web tool created to help users who still want to export G-code from their Carbide Create projects.

With **Carbide Create 7**, **G-code export is no longer available in the free version**. This project provides a simple alternative by making the conversion accessible directly from a browser.

The online version is available here:
https://iarchi.github.io/c2d-gcode/

The goal is to keep the process straightforward: open the tool, load your file, and generate the G-code you need.
